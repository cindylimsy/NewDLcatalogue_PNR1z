# NewDLcatalogue_PNR1z
Code and animations for the publication "A New Deep Learning Enhanced Induced Seismicity Catalogue at Preston New Road-1z, UK: Improved Completeness and New Structural Interpretations" (Seismica)

This repository includes:
1. the full deep learning catalogue for the PNR-1z site, UK - containing over 49,000 events, their locations in latlon, and x,y,z, whether they are clipped (clipped_binary), on which stations (clipped_stns) and the n of stations clipped (n_clipped_stns) and their moment magnitudes (Mw).
2. the "Event_and_Station' folder - containing the benchmark catalogue (PNR-1z_FullCatalogue.dat) with details of the injection stages (PNR-1z_Stages.dat), station locations and orientations (PNR-1z_Stations.dat, PNR-1z_Stations_orient.dat) and well paths for PNR-1z and PNR-2 (PNR-1z_Wellpath.dat, PNR-2_Wellpath.dat).
3. the 'Velocity_models' folder - containing the four calibrations shots at PNR-1z (*.bormod files, also containing density profiles), the average of the velocity models (velocity model used in this study)
